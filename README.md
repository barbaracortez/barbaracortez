## Proyectos destacados

### TurnosApp — [gestionaturno.com](https://gestionaturno.com)
SaaS multi-tenant de reserva de turnos para centros de estética y peluquerías. **En uso por cuatro negocios.**
- Frontend en **React + Vite + TypeScript** (Vercel)
- API en **Node.js / Express / TypeScript** (Railway) con **MongoDB Atlas**
- Aislamiento por tenant con **JWT**, modelo de prueba/suscripción y emails transaccionales con **Resend**
- Dominio propio con DNS, SPF, DKIM y DMARC configurados

### MOVE FIT — [Ver demo](https://movefit-teal.vercel.app/login?demo=1)
Plataforma de gestión para gimnasios: alumnos, pagos, comunicaciones, reportes y configuración.
- Frontend en **React + TypeScript + Vite** con design system propio (modo oscuro)
- Backend en **NestJS** con **PostgreSQL + Prisma**, deploy en Railway
- Notificaciones por WhatsApp y email

### Nexo CRM — [Ver demo](https://barbaracortez.github.io/dashboard-app/)
Panel comercial para equipos de ventas: métricas del mes, clientes, leads y pipeline de oportunidades.
- **React + Vite** con **React Router** y gráficos con **Recharts**
- Cuenta demo con datos que se guardan en el navegador · [Código](https://github.com/barbaracortez/dashboard-app)

### App de Solicitudes con aprobación — Power Platform
Solución completa para gestionar solicitudes internas, desde la carga hasta la aprobación y el análisis.
- Modelo relacional en **Dataverse**, empaquetado en una solución
- Apps **canvas** y **model-driven** con validaciones y reglas de negocio
- Aprobaciones con **Power Automate** y tablero en **Power BI** con Power Query y DAX

### Conexión 360 — Landing page del estudio
